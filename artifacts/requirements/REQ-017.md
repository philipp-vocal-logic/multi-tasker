## Statement
The `Orchestrator` shall deterministically generate an external project `AGENTS.md` guide covering bootstrapping, `Policy` (`policy/*.yaml`) customization, `PERM_POLICY_MODIFIED` commit rules, and the canonical artifact workflow, and write it to `AGENTS.md` during `mt initialize` when `AGENTS.md` does not already exist.

## Impact Analysis
- Updates `src/orchestrator/documentation_generator.py` to add `generate_external_agents_guide() -> str` without maintaining a duplicate static Markdown file.
- Updates `src/orchestrator/lifecycle.py` so `_scaffold_default_policies_and_gitignore` writes `repository_root / "AGENTS.md"` when missing, leaving this repository's internal `AGENTS.md` untouched.
- Updates `tests/test_interaction_logging.py` with a `TestContract` verifying external `AGENTS.md` generation and non-overwrite behavior.
