## Statement
Support configurable per-agent `Worktree` execution (`worktree_execution`) and per-role default `model` selection (`gemini-4-argon` for `RequirementAgent`, `SpecificationAgent`, `PlannerAgent`, and `ReviewAgent`; `gemini-3.8-flash-high` for `WorkerAgent`) across `Policy`, `Orchestrator`, and `mt run`.

## Impact Analysis
- Extends `policy/permissions.yaml` with `model` and `worktree_execution` under each agent role in `agents`.
- Updates `src/checkers/permissions_checker.py` and `src/orchestrator/prompt_builder.py` to validate agent execution settings and resolve `CLI > Artifact > Agent Role > Global Default` model precedence.
- Adds `src/orchestrator/stage_runner.py` and updates `src/cli/main.py` (`mt run --agent <role> --target <id>`) to execute any enabled agent role inside an isolated `Worktree` verified by `MergeGate`.
