## Statement
The `Orchestrator` role prompt synthesizer (`build_agent_prompt`) must use non-fixed identifier placeholders (`REQ-NNN`, `ESC-NNN`, `AC-XX`) in schema templates, `Escalation` contracts, and targetless example prompts, wrap synthesized prompt instruction lines to the project 88-character line length while surfacing `max_line_length=88` in `WorkerAgent` limits, and render canonical `Glossary` terms and `code_identifiers` from `policy/glossary.yaml`.

## Impact Analysis
- Replaces fixed example identifiers (`ESC-001`, `AC-01`, and counter-bound IDs in targetless example prompts) in `src/multi_tasker/orchestrator/prompt_builder.py` with non-fixed `PREFIX-NNN` / `AC-XX` placeholders so LLMs are not primed with colliding artifact numbers.
- Wraps synthesized prompt instruction lines to at most 88 characters, adds `max_line_length=88` to `WorkerAgent` `Source Limits`, and renders canonical `Glossary` terms with `code_identifiers`.
