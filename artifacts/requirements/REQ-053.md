## Statement
Harden greenfield multi-language (`python`, `ansi-c`, `rust`) support across architecture layer matching, `mypy` invocation, C and Rust comment/string/signature/trace parsing, stage prompt path scoping, worktree setup, and documentation generation.

## Impact Analysis
- Extracts `src/multi_tasker/checkers/language_parser.py` from `language_support.py` and updates `architecture_checker.py` and `clean_code_checker.py` to fix layer glob matching, C self/relative includes, `mypy` paths, and C/Rust regex false positives/negatives.
- Updates `language_presets.py`, `lifecycle.py`, `prompt_builder.py`, `prompt_context.py`, `lineage.py`, and `worktree.py` to fix preset layer globs, `review-agent` write scopes, worktree `.report` creation, and non-Python documentation and prompt synthesis.
- Adds `tests/test_multi_language_greenfield_hardening.py` covering `REQ-053:AC-01` through `REQ-053:AC-03`.
