## Statement
Support ANSI C (`ansi-c`, `.c`/`.h`) and Rust (`rust`, `.rs`) alongside Python across all deterministic `mt check` validators, `mt initialize --preset` policy scaffolding, `mt prompt` synthesis, and end-to-end `mt run --pipeline` execution.

## Impact Analysis
- Adds `src/multi_tasker/checkers/language_support.py` and updates `architecture_checker.py`, `clean_code_checker.py`, `limits_checker.py`, `glossary_checker.py`, and `code_and_git_traceability.py` to analyze `.c`, `.h`, and `.rs` files.
- Adds `src/multi_tasker/orchestrator/language_presets.py` and updates `lifecycle.py`, `lineage.py`, `prompt_builder.py`, and `prompt_context.py` to support `ansi-c` and `rust` presets, trace lineage, and prompt code contracts.
- Adds `tests/test_multi_language_pipeline.py` exercising checker violations and full E2E pipeline execution across Python, ANSI C, and Rust.
