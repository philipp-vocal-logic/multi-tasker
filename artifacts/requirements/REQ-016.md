## Statement
The `Orchestrator` shall support installing `multi-tasker` (`multi_tasker`) as a library for external repositories, scaffolding missing default `Policy` files and `.gitignore` entries during `mt initialize`, enforcing configurable internal package prefixes and layer directories in `mt check architecture`, and prioritizing `worktree_path` in `Worktree` subprocess `PYTHONPATH`.

## Impact Analysis
- Updates `pyproject.toml` and `policy/architecture.yaml` to expose the `multi_tasker` package namespace and allow `multi_tasker` imports.
- Updates `src/orchestrator/lifecycle.py` so `initialize_repository` copies missing default `policy/*.yaml` templates and ensures `.gitignore` includes `.worktrees/`, `.report/`, and `.mt_prompt.md`.
- Updates `src/checkers/architecture_checker.py` to derive scanned layer folders and internal package prefixes from `policy/architecture.yaml`.
- Updates `src/orchestrator/prompt_builder.py` and `src/orchestrator/stage_runner.py` to prepend `worktree_path` to `PYTHONPATH`.
