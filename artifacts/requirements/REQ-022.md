## Statement
The `Orchestrator` shall record accurate per-role `agent_role` telemetry in `record_task_event`, aggregate `MergeGate` pass rates and per-role invocation latencies via `summarize_pipeline_suitability`, and provide `mt run --evaluate "<intent>"` to bootstrap an isolated Git repository, execute the declarative pipeline, run `mt check all`, and output a JSON suitability summary.

## Impact Analysis
- Updates `src/orchestrator/interaction_logger.py` and `src/orchestrator/stage_runner.py` to pass `agent_role` into `record_task_event` and adds `summarize_pipeline_suitability`.
- Updates `src/orchestrator/lifecycle.py` with `bootstrap_evaluation_repository` to initialize a Git repository, set `intent_to_requirement` `approval_gate: "auto"`, seed `INT-001`, and commit the baseline state.
- Updates `src/cli/main.py` to support `--evaluate` on `mt run`.
- Updates `tests/test_stage_runner.py` and `tests/test_interaction_logging.py` with `TestContracts` while keeping all test modules under `400` lines.
