## Statement
Eliminate cross-stage prompt contradictions and missing context by including `Source Limits` and `Clean Code AST Rules` across engineering roles, adding a positive Python and `TestContract` Output Contract for `WorkerAgent`, and refining `Execution Steps` and Section 4 file rendering.

## Impact Analysis
- Updates `src/multi_tasker/orchestrator/prompt_builder.py` and `src/multi_tasker/orchestrator/prompt_context.py`.
- Updates `tests/test_interaction_logging.py` to verify cross-stage `Source Limits`, the `WorkerAgent` Python Output Contract, Section 4 deduplication and new-file status, and concrete stage paths.
