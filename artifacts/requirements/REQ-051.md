## Statement
Extract hardcoded build ignore lists, source file extensions, forbidden source calls, test discovery globs, and planner verification commands from Python code into `policy/agent_execution.yaml`, `policy/code_quality.yaml`, and `policy/traceability.yaml`.

## Impact Analysis
- Replaces hardcoded ephemeral entries in `common.py` and `DEFAULT_GITIGNORE_ENTRIES` in `lifecycle.py` with `clean_repo_invariants.ignored_ephemeral_globs` in `policy/agent_execution.yaml`.
- Adds `language`, `source_extensions`, and `ast_rules.forbidden_calls_in_src` (replacing `forbid_print_in_src`) in `policy/code_quality.yaml`, consumed by `common.py`, `architecture_checker.py`, `clean_code_checker.py`, `limits_checker.py`, `glossary_checker.py`, and `code_and_git_traceability.py`.
- Adds `test_file_glob`, `test_contract_verification_cmd`, and `implementation_verification_cmd` in `policy/traceability.yaml`, consumed by `code_and_git_traceability.py`, `lineage.py`, `prompt_context.py`, and `prompt_builder.py`.
