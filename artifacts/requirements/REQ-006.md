## Statement
Continually generate live repository documentation into `.report/specification.md` inside a gitignored `.report/` directory whenever `mt documentation` or any `Orchestrator` lifecycle mutation (`initialize`, `intent`, `approve`, `resolve`, `run`) executes.

## Impact Analysis
- Adds `.report/` to `.gitignore` and writes `.report/.gitignore` (`*`) alongside `.report/specification.md`.
- Updates `src/orchestrator/documentation_generator.py`, `src/orchestrator/lifecycle.py`, `src/cli/main.py`, and `tests/test_orchestrator.py`.
