## Statement
`initialize_repository` and `mt initialize` shall support a `--preset` option (`python` or `multi-tasker`, defaulting to `python`) so newly initialized repositories and `bootstrap_evaluation_repository` receive a generic Python `policy/architecture.yaml` layout (`src/domain/**`, `src/services/**`, `src/cli/**`, `tests/**`) by default while rejecting unknown presets with `[CLI_INVALID_PRESET]`.

## Impact Analysis
Updates `src/multi_tasker/orchestrator/lifecycle.py`, `src/multi_tasker/cli/main.py`, `tests/test_lifecycle.py`, and `tests/test_stage_runner.py`.
