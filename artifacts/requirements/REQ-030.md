## Statement
`build_agent_prompt` shall include the explicit 3-argument `@traces("REQ-NNN", "AC-XX", "SPEC-NNN")` decorator contract (`from multi_tasker.domain.models import traces`) in `planner-agent` and `worker-agent` prompts, and `_step_declarative_stage` shall pass `options[2] or "agy"` to `run_scheduled_tasks` so `mt run --pipeline` and `mt run --evaluate` invoke `worker-agent` automatically.

## Impact Analysis
Updates `src/multi_tasker/orchestrator/prompt_builder.py`, `src/multi_tasker/orchestrator/stage_runner.py`, and `tests/test_interaction_logging.py`.
