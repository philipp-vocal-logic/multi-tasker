## Statement
The system must decompose all Python modules exceeding 400 lines (`lifecycle.py`, `traceability_checker.py`, `test_lifecycle.py`, and `test_orchestrator.py`) into focused, single-responsibility modules under 360 lines with zero backward-compatibility shims or re-exports.

## Impact Analysis
- Extracts parallel `Worktree` `Task` execution from `src/orchestrator/lifecycle.py` into `src/orchestrator/task_runner.py` and updates `src/cli/main.py` in lockstep.
- Extracts `TestContract`, `target_files`, and Git commit `Traceability` validation from `src/checkers/traceability_checker.py` into `src/checkers/code_and_git_traceability.py`.
- Rebalances `tests/test_lifecycle.py` and `tests/test_orchestrator.py` by extracting prompt synthesis, execution environment, and state transition tests into `tests/test_transitions_and_execution.py`.
